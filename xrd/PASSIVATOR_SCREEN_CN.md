# 钝化剂筛选 XRD 结果详述（六个样品）

数据：Generations-0726-XRD，control + 钝化剂 1–5，全部沉积在 ITO 基底上。
分析工具：`perovskite-xrd-protocol`（固定协议测量层）。
本文所有数值均取自已保存的结果表 `xrd/results/master_figure_data.csv` 与
`xrd/results/passivator_peak_tables.csv`，未凭记忆书写。

## 0. 采集条件与数据完整性

从 `.mdi` 头文件读取（不是假设）：

| 项目 | 数值 |
|---|---|
| 波长 | Cu Kα **λ = 1.54184 Å**（加权平均值，**不是** Kα₁ 的 1.540598 Å） |
| 扫描范围 | 5–50° 2θ |
| 步长 / 每步计数时间 | 0.05° / 0.3 s |
| 仪器 | DX-27Mini，40 kV/10 mA，狭缝 1°/1°/0.03 mm，单色器开 |
| 重复次数 | **每个薄膜仅 1 次扫描（n = 1，无重复）** |

六个样品的采集条件**完全一致**，因此允许比较绝对强度。每个 `.txt` 的强度值
与其 `.mdi` 内嵌计数逐点核对通过。

## 1. 物相：六个样品是同一个相

八个反射在每个样品中都能指标化到赝立方晶胞，
N = h²+k²+l² = 1, 2, 3, 4, 5, 6, 8, 9，**没有任何未指标化的薄膜反射**。

结论：没有新相、没有相变、没有分解为其他结构。所有差异都在
**PbI₂ 含量**和**扫描几何**这两件事上。

## 2. 关键约束：位置和宽度的差异是仪器造成的

ITO 基底在每个薄膜下面都是同一块，物理上不可能改变。但它的衍射峰变了：

- 位置漂移 **0.35°**
- 半高宽变化 **71%**

而薄膜峰跟着它一起动：

| 检验 | 结果 | 判定 |
|---|---|---|
| 钙钛矿 100 位移 vs ITO 位移 | 斜率 **1.08**，r = **0.986** | 共同的几何偏移（样品高度/位移），不是晶格变化 |
| 薄膜半高宽 vs ITO 半高宽 | r = **+0.88** | 各次扫描的仪器展宽不同 |

**关于回归是否包含 control：包含，且必须包含。**

以 control 为参考只是把两个坐标轴同时平移一个常数，而斜率与相关系数对平移不变
——用位移回归和用绝对角度回归得到的是同一条线（已数值验证，差异 ~1e-14）。
control 落在 (0, 0) 是坐标原点的位置，不是人为造出的锚点；它仍是一个真实观测，
剔除它等于丢弃一个数据点。

留一法（逐一剔除，并改用另一片薄膜作参考）：

| 剔除 | n | 斜率 | r | p |
|---|---|---|---|---|
| control | 5 | 1.019 | 0.991 | 0.0011 |
| P1 | 5 | 1.087 | 0.987 | 0.0017 |
| P2 | 5 | 1.076 | 0.985 | 0.0022 |
| P3 | 5 | 1.231 | 0.929 | 0.0224 |
| P4 | 5 | 1.119 | 0.993 | 0.0007 |
| P5 | 5 | 1.061 | 0.986 | 0.0020 |

斜率始终在 1.02–1.23，r 始终 > 0.93，p 始终 < 0.023。**剔除 control 后结论反而
更强**（斜率 1.019 更接近 1，r = 0.991 更高）。宽度检验用的是绝对半高宽，
control 并非结构性零点，剔除后 r 由 +0.873 变为 +0.906，同样不依赖 control。

**因此 Δa 与 ΔD 在这六次扫描之间 NOT COMPARABLE（不可比较）。**

数值仍然计算并保留在表中，但样品之间的差值是仪器来源的：

- 赝立方 a 表观范围 6.2987–6.3096 Å，跨度 0.011 Å；而最大模型不确定度为
  0.0075 Å ——**跨度与不确定度同量级，并未明显超出**。
- 表观畴尺寸 22.6–87.7 nm，其排序几乎完全由该次扫描的对准质量决定
  （表观 D 与 ITO 半高宽 r = −0.79）。

另外：ITO 峰在 6 个样品中的 5 个里**比薄膜峰还宽**，说明它的宽度由 ITO 自身
晶粒尺寸主导，**不能当作仪器分辨率标样**——强行反卷积会使表观尺寸发散到无穷。

## 3. 逐样品结果

| 样品 | PbI₂（占钙钛矿 Bragg %） | p（bootstrap） | 钙钛矿/ITO 相对 control | 211/220 | 表观 D (nm) | 钙钛矿峰中位半高宽 (°) |
|---|---|---|---|---|---|---|
| **control** | 2.66 | 4.3×10⁻¹⁴ | — | 0.29 | 46.7 | 0.207 |
| **P1** | 3.85 | 1.0×10⁻²³ | +7% | 0.39 | 87.7 | 0.157 |
| **P2** | 3.40 | 3.9×10⁻¹⁵ | −2% | 0.45 | 33.0 | 0.285 |
| **P3** | 1.14 | 0.023 → **未检出** | **−41%** | 0.78 | 22.6 | 0.380 |
| **P4** | 1.73 | 1.4×10⁻⁴ | −9% | 0.55 | 27.6 | 0.319 |
| **P5** | **10.04** | 5.2×10⁻⁶⁴ | +7% | 0.70 | 79.0 | 0.166 |

Bonferroni 显著性阈值（检验了 12 个候选位置）α = 0.0042。

**control** — PbI₂ 2.66%，作为参考点。峰形锐利。

**P1** — PbI₂ 3.85%，仅次于 P5；但总衍射强度未变（归一化指标 +7%，在噪声内）。
它是除 P5 外对准最好的一次扫描，所以表观尺寸看起来最大——这是几何效应。

**P2** — PbI₂ 3.40%，强度未变（−2%）。其**原始** Bragg 积分下降 14.5%，
但该指标未对束流和对准做归一化，而归一化指标没有显示任何变化，
因此不应据此判定薄膜发生了改变。

**P3 —— 两个独立维度上的异常样品。**
- 唯一**没有检出 PbI₂ 相容峰**的薄膜（p = 0.023，未通过 α = 0.0042）；
- 唯一在归一化强度上超出噪声的样品：**−41%**。

同时它的峰最宽（中位 0.380°），扫描对准最差（ITO 半高宽 0.662°，漂移 0.35°），
所以它的尺寸和晶格数值在全组中最不可信。强度下降是真实的，但**无法在此区分**
其原因是结晶物质更少、薄膜更薄、还是表面部分非晶化。

**P4** — PbI₂ 1.73%，低于 control；强度基本未变（−9%）。全组中最“安静”的样品。

**P5 —— PbI₂ 10.04%，是 control 的 3.8 倍**，显著性极高（p ~ 10⁻⁶⁴），
且其 PbI₂ 峰是全组最锐、最强的。但钙钛矿总强度未变（+7%），
说明**这不是体相薄膜的分解，而是表面相的大量富集**。

### PbI₂ 排序的稳健性

- 无论以全部 8 个钙钛矿反射归一化，还是仅以最邻近的反射归一化，
  **排序完全相同**（Spearman ρ = 1.00）；
- PbI₂ 百分比与失准代理量**负相关**（r = −0.69），即最高值来自对准最好的扫描，
  所以这个趋势不是几何假象。

排序（低 → 高）：**P3 < P4 < control < P2 < P1 < P5**

## 4. 结晶度：没有任何钝化剂使薄膜非晶化

Bragg/total 指标在六个样品中为 **0.213–0.230**，相对 control 的偏差全部在 7.4%
以内。无论钝化剂做了什么，都没有破坏结晶性。

注意：该指标是**固定协议下的比较性结晶度指数**，不是绝对结晶度；它依赖扫描范围、
背景、计数时间、膜厚和仪器通量，只在协议完全一致时可比。

## 5. 织构：六个薄膜共享同一织构取向

全部六个薄膜都**强织构化**（TC = 1.0 代表无取向粉末）：

- 211 增强，最高 TC = 3.67；300 增强，最高 TC = 2.38
- 100 与 200 被压低，TC = 0.17–0.33

六条织构曲线两两秩相关中位数 ρ ≈ 0.98，即**形状是同一个**。

211/220 强度比确实存在表观趋势（control 0.29 → P3 0.78），且 P5 是唯一最强峰为
210 而非 220 的样品。**但不应把它作为钝化剂效应报告**，理由是它与一个混杂量
显著相关：

| 变量 | Pearson r (p) | Spearman ρ (p) |
|---|---|---|
| ITO 半高宽（对准代理） | +0.42 (0.407) | +0.03 (0.957) |
| 钙钛矿中位半高宽 | +0.49 (0.327) | +0.54 (0.266) |
| \|基底位移\| | +0.63 (0.179) | +0.54 (0.266) |
| **总 Bragg 强度** | −0.75 (0.083) | **−0.83 (0.042)** |
| PbI₂ % | +0.21 (0.688) | −0.26 (0.623) |

五项检验中**唯一越过 α = 0.05 的是与总 Bragg 强度的秩相关：ρ = −0.83,
p = 0.042**（方向为负：总强度越低，211/220 越高）。这正是一个混杂信号——
衍射越弱的样品，弱反射的相对权重越容易被抬高，而不是钝化剂改变了取向。

两点补充：
- 该结果在 5 项检验的 Bonferroni 校正下（α = 0.010）**不再显著**；
- 与 PbI₂ 排序的秩相关仅 ρ = −0.26（p = 0.623），即织构趋势与化学量并不同步。

因此：现有数据既不足以确立织构趋势，也已给出它可能是强度混杂的直接证据。
需要重复样品才能判断。

## 6. 结论状态一览

| 量 | 状态 | 原因 |
|---|---|---|
| 物相归属（同一赝立方相） | **VALID** | 八个反射在六个样品中全部指标化 |
| PbI₂/钙钛矿 Bragg 比 | **VALID**（P3 为 provisional） | 扫描内比值；排序稳健 ρ = 1.00 |
| 比较性结晶度指数 | **VALID** | 六次扫描协议完全一致 |
| 织构系数 | **VALID** | 约定锁定；已排除基底重叠反射 |
| 晶格常数 Δa | **NOT COMPARABLE** | 峰位随基底 1:1 移动（r = 0.986） |
| 晶粒（畴）尺寸 ΔD | **NOT COMPARABLE** | 峰宽随基底变化（r = +0.88） |
| 绝对结晶度 DOC | **仅给区间** | 非晶包与平背景数学简并 |
| 微应变 | **抑制不报** | Williamson–Hall 斜率在 6 个中有 5 个为负 |

## 7. 站得住的结论

1. **六个薄膜是同一个结晶良好、强织构的钙钛矿相**，没有新相或分解产物。
2. **P5 表面 PbI₂ 为 control 的 3.8 倍**，而体相钙钛矿强度未变——是表面富集，
   不是体相分解。
3. **P3 检测不到 PbI₂，且衍射强度低 41%**，是全组唯一强度真正下降的样品。
4. **没有任何钝化剂使薄膜非晶化。**
5. **本批次无法给出 Δa 和 ΔD**——这是采集时的对准问题，分析无法补救。

## 8. 下一批建议（按优先级）

1. **一次装样、不动样品高度，连续测完整组**；或每个薄膜加内标（Si/LaB₆）。
   这是恢复 Δa 与 ΔD 的唯一途径。
2. **裸 ITO 基底扫描**——确认基底贡献与 30.2° 归属（目前为 provisional）。
3. **LaB₆ 或 Si 标样**——给出真实仪器分辨率函数，使尺寸从"条件值"变为绝对值。
4. **重复样品**：每个条件至少 2 片，才能判断织构趋势是真实效应还是批次散差。
5. 优先复测 **P5 与 P3**——这两个是本数据集唯一确立的材料层面差异。
