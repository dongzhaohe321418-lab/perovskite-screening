# WP3-V5 and WP3-V4: is V3's "partial" reading stable under the seed, and is the loss ordered with the learning rate? (pre-specification)

Written 2026-11-18T11:10Z, after V1, V1b, V2 and V3 were read (`WP3_RETESTS.md`, commit 582e576) and before any V4 or V5 step.
Post hoc with respect to WP3 and to V1-V3; diagnostics, not adoption tests. No model is adopted on this evidence.

**Why.** V3 (the WP3 command with only `--lr 0.0001`) gave P1 = 47.04 meV and P3 = 15.76 meV/A: "partial". P1 lies
2.96 meV under the 50 meV line of its rule, on one seed. Every arm so far has one seed, so the size of the seed effect
on P1 is unknown. Separately, the documented default rate for single-head fine-tuning is reported to be 1e-3 (project
literature check; not re-read by the lead), between WP3's 0.005 and V3's 1e-4, and no arm has run there.

**Arms** (run in this order, one at a time, locally on CPU; mace-torch 0.3.16 as before).
- **V5.** The V3 command unchanged except `--seed 124` (name wp3v5). Seed 124 is the next integer after 123; no other
  seed is run or looked at.
- **V4.** The WP3 command unchanged except `--lr 0.001` (name wp3v4, seed 123, EMA decay 0.99 as WP3 and V3).

**Read-outs** (fixed now; as V3). With `eval_v1.py` on the selected model: P1 (m30 Sr far-referenced E_b error RMS)
and P3 (force RMSE on the 46 m30/m32 test frames). The far-referenced Sr hinge and flank E_b of m05, m21 and m30 at
every kept checkpoint (the script of `traj_v3.py` with the run directory changed) are reported, not read by a rule.

**Readings** (fixed now). The limit of 20 meV below is the non-interpretation limit already used for P1 differences
(V1_PRESPEC).
- Each arm is first classed by V3's own rule: "kept" (P1 <= 25 meV and P3 <= 45 meV/A), "lost" (P1 > 50 meV with
  P3 <= 45), "under-trained" (P3 > 45), otherwise "partial".
- **V5, seed effect.** d = |P1(V5) - 47.04|.
  - d <= 20 meV: V3's result is reproduced within the limit. The statement "lowering the rate alone keeps the sign and
    about half of the hinge value" stands for two seeds, with both classes reported.
  - d > 20 meV: the seed effect on P1 exceeds the limit. Then no single-seed P1 difference between arms smaller than
    d is interpreted anywhere in the note, the classes of V1-V4 are reported as single-seed classes only, and the
    statement about "half of the hinge value" is withdrawn in favour of the two values.
  - If V5 is "under-trained", it says nothing about the seed effect on P1; reported as such.
- **V4, order with the rate.** P1_low = mean of P1(V3) and P1(V5) (V3 alone if V5 is under-trained).
  - "ordered with the rate": P1(V4) - P1_low > max(20 meV, d) and P3(V4) <= 45.
  - "no resolved dependence between 1e-4 and 1e-3": |P1(V4) - P1_low| <= max(20 meV, d) and P3(V4) <= 45.
  - "reversed": P1(V4) - P1_low < -max(20 meV, d) and P3(V4) <= 45; reported as unexplained.
  - "under-trained": P3(V4) > 45.
  An "ordered" outcome is a dose-response observation over three rates on one data set; it is not a demonstration
  that the rate is the cause, and replay (V2) remains untested at WP3-level forces.
- Nothing here changes the reading of V1-V3 as already published, except as the d > 20 meV line states.

**Limits.** The used test set; P1 on 3 sites of one host; V4 has one seed and V3/V5 two; the selected epoch is
mace-torch's (lowest m21 validation loss), which is itself a choice that varies with the seed.
